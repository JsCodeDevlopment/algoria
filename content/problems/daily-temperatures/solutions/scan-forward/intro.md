### A ideia que qualquer um percebe

Para cada dia, “olha sempre para a direita” até encontrares **o primeiro número maior**.

### O aviso intuitivo sobre performance

Este caminho faz muitíssimos passos repetidos: para cada dia voltas a varrer a frente como se não tivesses memória. Quando a lista cresce, a versão com **pilha** resolve o mesmo tipo de pergunta com uma única passagem mais inteligente.
